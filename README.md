# Sudarshan Rajkumar - Personal Portfolio

A clean, responsive personal portfolio website showcasing my technical toolkit, leadership roles, and current focus in software engineering. 

**Live Demo:** [https://personalportfolioo-zeta.vercel.app/](https://personalportfolioo-zeta.vercel.app/)

## 🚀 About the Project

This is a static multi-page portfolio designed with a focus on speed, minimal overhead, and clean aesthetics. It highlights my current work in competitive programming (Data Structures & Algorithms), my involvement in tech communities (Google Gemini, AWS, AMD), and my foundational skills in software and hardware logic.

## 🛠️ Tech Stack

*   **HTML5:** Semantic structure and multi-page routing.
*   **CSS3:** Custom styling, smooth transitions, and responsive layout without the need for heavy external frameworks.
*   **Vercel:** Continuous deployment and hosting.

## 📂 Project Structure

*   `index.html` - Home page detailing my current focus and tech event participation.
*   `toolkit.html` - Overview of my primary languages and tools (C++, Python, Verilog, etc.).
*   `leadership.html` - Summary of my community outreach and ambassador roles.
*   `offscreen.html` - A quick look at my life outside of coding.
*   `style.css` - Global stylesheet shared across all pages.
